📚 Mecanismos de Consumo Web Abordados

Este proyecto demuestra de forma práctica cómo consumir APIs REST utilizando la función nativa fetch() de JavaScript/TypeScript, aplicando separación de responsabilidades con un archivo de servicio independiente y tipado estático con interfaces.

1. async / await (Sintaxis Moderna)

Pausa la ejecución de la función hasta que la promesa se resuelva, permitiendo escribir código asíncrono con estilo síncrono y legible. 

async function getCharacters() {
  try {
    const res = await fetch(url);
    if (!res.ok) throw new Error(res.statusText);
    const data: ApiResponse = await res.json();
    return data;
  } catch (error) {
    console.error(error);
  }
}

2. Promesas (.then / .catch)

Encadenamiento funcional donde cada .then() procesa el resultado del paso anterior y .catch() captura cualquier fallo de red. 

function getCharacters() {
  fetch(url)
    .then(res => res.json())
    .then((data: ApiResponse) => {
      render(data);
    })
    .catch(error => {
      mostrarError(error);
    });
}

Ventajas de TypeScript + Tailwind CSS

  • Tipado Fuerte: Interfaces para la respuesta evitan errores de propiedades inexistentes y facilitan el autocompletado en el editor.
  • Modularidad: La lógica de petición HTTP reside en src/services/api.ts, separada de la manipulación del DOM.
  • Diseño Responsivo: Grid adaptable de 1 a 4 columnas sin escribir cientos de líneas de CSS manual.
